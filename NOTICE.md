# Aviso de atribuição

Este projeto é uma adaptação do **BG3 Inspired Hotbar**, originalmente publicado por BragginRites e Dapoulp em:

https://github.com/BragginRites/bg3-inspired-hotbar

O código original foi disponibilizado sob a licença MIT, preservada em `LICENSE.md`.

A versão para Tormenta20 substitui o núcleo de integração com D&D 5e por uma implementação própria para Tormenta20 1.5.015, além de acrescentar interface, estilos, testes, documentação e comportamento específicos do sistema.
